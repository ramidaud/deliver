Connection

A GitHub token that can write to this one repo. Kept only in this browser — never sent anywhere but api.github.com.

Don't have a token? Generate one on GitHub →
  1. Token name: anything, e.g. gallery admin
  2. Resource owner: your account
  3. Repository access → Only select repositories → pick this repo
  4. Repository permissions → Contents → set to Read and write
  5. Generate token, copy it, paste it above (GitHub only shows it once)

Starting a new client repo from the template? The token is scoped to specific repos, so add the new one to its repository list or publishing will fail with a 403.
